# All Subjects Covered in Question Paper PDFs
> Organized by Semester — verified against actual syllabi across R13, R15, R16, R18, R22

---

## Normalization Key

| Status | Meaning |
|---|---|
| ✅ SAME | Syllabus content verified as identical or near-identical — can be merged |
| ⚠️ SIMILAR | Same broad topic area but different content/units — keep separate, note relationship |
| ❌ DIFFERENT | Entirely different syllabus — must NOT be merged |

## 1-1 (1st Year, Semester 1)

1. **Mathematics-I** *(Linear Algebra & Differential Equations)*
   - R13: Matrices, Eigen Values, Calculus, Diff Equations, Laplace Transform
   - R16: Linear Algebra, Differential Equations, PDEs
   - R22: **Matrices and Calculus** — covers Matrices + Calculus only (subset)
   - ❌ **Matrices and Calculus (R22) is NOT the same as Mathematics-I** — R22 splits the content across two subjects

2. **Engineering Physics** *(also: Engineering Physics-I)*
   - R13: Crystallography, Quantum Mechanics, Dielectric/Magnetic properties, Optics/Lasers, Semiconductors
   - R16 "Engineering Physics-I": Interference/Diffraction, Lasers, Fiber Optics, Crystallography, X-ray Diffraction
   - R16 "Engineering Physics": **Identical unit topics to Engineering Physics-I** (word-for-word same syllabus)
   - ✅ **Engineering Physics and Engineering Physics-I (R16) are the SAME** — just named differently

3. **Engineering Chemistry**
   - R13 & R16: Same core topics — Electrochemistry, Polymers, Water Treatment, Fuels, Phase Rule
   - R22: Same subject — verified same content
   - ✅ **Engineering Chemistry is the SAME across R13, R15, R16, R22**

4. **Engineering Drawing** *(also: Computer Aided Engineering Graphics R22)*
   - R13/R15: Orthographic Projections, Curves, Solids, Isometric Projections
   - R22 CAEG: Computer-aided version of the same drawing concepts
   - ⚠️ **SIMILAR but not identical** — R22 uses CAD tools; keep separate with note

5. **English** *(also: Professional Communication in English R16)*
   - R13: Reading, Writing, Grammar skills
   - R16: Same communication/language skills focus
   - ✅ **SAME subject** — different name only

6. **Computer Programming** *(also: Programming for Problem Solving R18/R22)*
   - R13: C programming — pointers, arrays, structures, linked lists, sorting
   - R18/R22: "Programming for Problem Solving" — also C programming with same topics
   - ✅ **SAME subject** — verified same content

7. **Basic Electrical Engineering** *(also: Basic Electrical and Electronics Engineering R16)*
   - R13/R15/R18: Ohm's law, AC/DC circuits, Transformers, Machines, Instruments
   - R16 "Basic Electrical and Electronics Engineering": Same + includes Electronics components
   - ⚠️ **SIMILAR** — R16 adds Electronics; keep as variants but note overlap

8. **Mathematical Methods** *(R13/R15 only)*
   - Topics: Interpolation, Numerical Methods, Fourier Series, PDEs, Vector Calculus
   - ❌ **NOT the same as Mathematics-I** — entirely different syllabus (Numerical + Fourier, no Eigen values/Linear Algebra)

9. **Engineering Mechanics** *(R16 only)*

10. **Matrices and Calculus** *(R22 1-1 only)*

## 1-2 (1st Year, Semester 2)

1. **Mathematics-II** *(Advanced Calculus — Laplace Transforms, Beta/Gamma, Multiple Integrals, Vector Calculus)*
   - ❌ **NOT the same as Mathematics-I or Mathematics-III**

2. **Mathematics-III** *(Statistical & Numerical Methods — Probability, Distributions, Numerical Analysis)*
   - ❌ **NOT the same as Mathematics-I, II, or Probability & Statistics (R13 2-1)**
   - ⚠️ Mathematics-III overlaps with Probability & Statistics (R13 2-1) but has more Numerical Methods

3. **Ordinary Differential Equations and Vector Calculus** *(R22 only)*
   - Covers: ODEs, Laplace Transforms, Vector Differentiation/Integration
   - ⚠️ **SIMILAR to Mathematics-II (R16)** — overlapping topics but not identical; keep separate

4. **Engineering Physics II** *(R16 only)*
   - Topics: Quantum Mechanics, Statistical Mechanics, Semiconductors, Dielectric/Magnetic properties
   - ❌ **NOT the same as Engineering Physics-I (R16)** — different units (Part II of the same subject)

5. **Computer Programming in C** *(R16 only)*
   - ✅ **SAME as Computer Programming (R13/R15)** — identical C programming content

6. **Engineering Graphics** *(R16/R18)* / **Engineering Drawing** *(R22)*
   - ✅ **SAME subject** across R16, R18, R22 — same drawing topics

7. **Applied Physics** *(R18/R22)*
   - Covers: Quantum Mechanics, Optics, Semiconductors, Lasers, Fiber Optics
   - ⚠️ **SIMILAR to Engineering Physics (R13)** — same broad topics but different organization; keep as variants

8. **Electronic Devices and Circuits** *(R22)*

9. **English for Skill Enhancement** *(R22 only)*
   - ✅ **SAME as English (R13) / Professional Communication in English (R16)**

## 2-1 (2nd Year, Semester 1)

1. **Data Structures**
   - R13/R15/R16/R18/R22: All cover linked lists, stacks, queues, trees, graphs, sorting, searching
   - ✅ **SAME across all regulations** — core DSA content identical

2. **Digital Logic Design** *(also: Digital Electronics R22)*
   - R13/R15/R16: Number systems, Boolean algebra, Combinational/Sequential circuits, Memory
   - R22 "Digital Electronics": Same topics
   - ✅ **SAME subject** — Digital Electronics is just the R22 name for Digital Logic Design

3. **Mathematical Foundations of Computer Science**
   - R13/R15/R16: Logic, Relations, Functions, Combinatorics, Graph Theory
   - ✅ **SAME across R13, R15, R16**

4. **Probability and Statistics** *(also: Computer Oriented Statistical Methods R18/R22)*
   - R13: Random Variables, Distributions, Sampling, Hypothesis Testing, Queuing Theory, Markov Chains
   - R18/R22 "Computer Oriented Statistical Methods": Similar content — Probability, Statistics, Numerical orientation
   - ⚠️ **SIMILAR but not identical** — R13 includes Queuing Theory & Markov Chains which R22 may not

5. **Mathematics-IV** *(R16/R18 only)*
   - Covers: Complex Analysis, Special Functions, or advanced topics depending on branch
   - ❌ **NOT the same as Mathematics-I, II, or III**

6. **Object Oriented Programming through Java** *(R16/R22)* / **Java Programming** *(R13/R15 in 2-2)*
   - R13/R15 "Java Programming" (in 2-2): OOP → Inheritance → Exception Handling → Collections/JDBC → GUI/Applets
   - R16/R22 "OOP through Java" (in 2-1): Same 5-unit structure, same topics
   - ✅ **SAME subject** — only regulation placement differs (R13/R15 put it in 2-2; R16/R22 in 2-1)

7. **Computer Organization** *(R13/R15/R16)* / **Computer Organization and Architecture** *(R18/R22)*
   - R13: CPU, I/O, Memory, 8086 Assembly Programming
   - R18/R22: Same core + architectural concepts
   - ✅ **SAME subject** — "and Architecture" is just an expanded name

8. **Basic Electrical Engineering** *(R13/R15 in 2-1)*
   - Same as 1-1 BEE entry above

9. **Electronic Devices and Circuits** *(R13 in 2-1)*
